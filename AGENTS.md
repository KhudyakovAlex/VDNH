# VDNH · павильон 75, этаж 1

Веб-SCADA: тёмный хром + Three.js план. Свет кликом/диммером/группами/сценариями. Локации деревом, на родителях клик по модели = навигация.

Ответы пользователю: кратко по-русски, без простыней и без дампов кода. Вопросы — нумерованные варианты, первый оптимальный.

## Запуск

- Разработка: `python serve.py` из корня репо, корень статики — `Test/`, порт **80**, bind `0.0.0.0`.
- Этот ПК: http://127.0.0.1/
- Портатив: `start.bat` + `portable-serve.ps1` + папка `Test` → http://127.0.0.1:8080/ (PowerShell, без Python).
- `file://` в Chrome не работает (модули + GLB). Не предлагать «просто открой html», если не просят.

Нужные файлы отдачи: `Test/index.html`, `app.js`, `style.css`, `floor1.glb`, `logo.jpg`, `vendor/`. IFC/SKP/DWG в `Test/` — исходники, не для портатива.

## Камера

Y-up. OrbitControls: ЛКМ pan, ПКМ rotate, wheel `zoomToCursor`. FOV 40. `minPolarAngle` 0.08 (вид сверху — 0.02, `flat`).

Перелёт: сферический lerp + подъём `sin(πe)`, ease. `applyLocation(id)` / `flyTo`. Домик и «Этаж 1» = `floor1` (`HOME_POS` / `HOME_TARGET`, rotZ 0.5206).

ЛКМ по свету не должен глушить Orbit: не стопать pointerup у controls, иначе залипает панорама. Диммер на 1 с — тогда `controls.enabled = false`, на pointerup снова включить **до** того как Orbit получит up.

## Локации

Дерево `LOC_CHILDREN` / кнопки `.loc` + `data-loc`:

```
floor1          Этаж 1
  hall1         Выставочный зал 1
    hall1zal    Зал
    tech        Техпомещения
    restrooms   Санузлы
    admin       Администрация
    meeting     Переговорная
  hall2         Выставочный зал 2
    hall2zal    Зал
    admin2      Администрация
  lobby         Вестибюль
    entrance    Вход
    hall        Холл (вестибюля, не путать с hall1)
    security    Охрана
    accounting  Бухгалтерия
```

Лист = нет детей в `LOC_CHILDREN` (`isLeafLoc`).

- **Лист:** клик/диммер/группы по свету.
- **Не лист:** свет не управляется, ховера света нет. Клик по невидимой зоне ребёнка (`rebuildNavZones`, AABB светильников + pad) → `applyLocation` + `setActiveLoc`. При перекрытии зон — меньший объём.
- **Esc** → родитель (`locParent`). На `floor1` ничего. Если открыто имя сценария — Esc только закрывает поле.

## Привязка светильников

Имена из GLB: предки `D-…`. Списки в `LOC_FIXTURES` (диапазоны `locIds`).

`assignedLoc(fix)`:

1. Имя в `LOC_OWNED` (hall1/hall2/entrance/accounting/security) → этот id; для hall1/hall2 наружу отдаём `hall1zal` / `hall2zal`.
2. Иначе ближайшая камера среди оставшихся локаций (скип: floor1, lobby, hall1, hall2, hall1zal, hall2zal, entrance, accounting, security) либо `hall`.

Спец. выборки `fixturesForLoc`:

- `floor1` — все.
- `lobby` — все, кроме списков hall1 и hall2.
- `hall` (холл вестибюля) — не в `LOC_OWNED`.
- остальные — `id` + потомки по `assignedLoc`.

Дежурный Вз-подлокаций (тех/санузлы/…) = nearest по остатку, не по спискам залов. Списки залов не пересобирать «по камере».

Новые ID: Shift-выделение → кнопка **Светильники** → пользователь кидает список + имя локации.

## Свет

`COL_OFF` тёмно-серый. 0% = выкл. С ≥1% — тёмно-жёлтый `COL_DIM`, до рыжего `COL_ON`. Выкл кликом с level 0 → следующий клик 100%.

Клик — вкл/выкл группу (`groupFor`: выделение, иначе `lightGroups`, иначе один). Контуры (`spawnRipple`) у всех в группе. Удержание 1 с — вертикальный диммер, мышь = тумба, старт с 0% если все были выкл.

Shift: рамка/лассо (кнопки справа при зажатом Shift). Только на листе имеет смысл для управления.

## Группы

`lightGroups` + черновик `editGroup`. MST (Kruskal), белые кружки (диаметр ≤ 1/10 макс. габарита светильника) и линии. Граф виден и после выхода из режима.

Кнопка групп слева от домика, красная обводка как «Павильон 75». В режиме свет не кликается. Клик: снять / добавить / перенести из другой (перенос в данные — на галке). Над группой: галка (зафиксировать, можно следующую), крестик (отмена черновика), «Разобрать группу». Выход из режима тоже фиксирует. Shift-выделение в режиме: нет черновика → новая группа, есть → дописать.

Предустановки в `applyPresetGroups` (диапазоны D-1010… / D-1020… и т.д.) — визуальные группы, не локации.

## Сценарии

Справа внизу. **Аварийный** — все на 100%, любая локация. **Дежурный** — 15% у `fixturesForLoc(currentLoc)`.

Пользовательские: `+` → снимок света **текущей** локации → поле имени → Enter. Клик — применить. ПКМ — `confirm` удаление. Ключ `localStorage`: `vdnh-scen`. Свои на каждую локацию.

## UI-мелочи

Хром `#1e2c39`, без лишних скруглений на панелях модели. Локации слева сверху, сценарии справа снизу. Координаты/светильники слева снизу. Вид сверху не сбрасывает target.
